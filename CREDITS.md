Design and implementation notes:

- Distribution follows the [shadcn registry](https://ui.shadcn.com/docs/registry) format (`registry.json` + `/r/{name}.json`).
- Visual language uses CSS variables so light/dark themes stay consistent across primitives and effects.
- The shadcn/ui base set includes the newer official items (field, input-group, button-group, kbd, empty, item, native-select, combobox, direction). `date-picker` and `typography` have official docs pages but **no standalone registry JSON** (404 on `/r/styles/new-york-v4/{name}.json`); they are provided as documented compositions. Combobox depends on `@base-ui/react` (MIT). Direction uses a small React context instead of the unified `radix-ui` package.
- Additional text, background, interaction, card, button, navigation, and page-transition effects were ported from Magic UI, Animata, Motion Primitives, Cult UI, Fancy Components, Kibo UI, and Origin UI (all MIT), or written as originals when a similar effect was needed.
- Origin UI was taken only from the MIT `apps/origin/` directory of `cosscom/ui`. The rest of that repository is AGPL and was not used.
- Batch 4 adds GPU backgrounds via `@paper-design/shaders-react` 0.0.81+ (Apache-2.0 wrapper only; shader source is not copied), liquid-glass-react (MIT, with a CSS fallback), Number Flow, prompt-kit-style AI input/message, Tailark-inspired marketing blocks, Magic/Eldora device frames and terminal, Tiptap/Kibo editor, plus original tree-view and onboarding tour.
- Batch 5 adds TanStack Virtual lists, react-photo-album + yet-another-react-lightbox galleries, react-phone-number-input, frimousse emoji picker, a Kibo-style native video player (Vidstack not vendored), wavesurfer.js (BSD-3-Clause) waveforms, original form inputs, dashboard/ecommerce page blocks, Smooth UI holographic foil, and Kokonut free MIT toast/notification/spoiler/hold-particle-tear buttons/flow-field/halftone. Spectrum UI was used only as inspiration. GSAP, tldraw, and Kokonut Pro were not used.
- Batch 6 Group A ports PavelDoGreat WebGL-Fluid-Simulation (MIT), Paper Shaders pack 2 (Apache-2.0 wrapper), Fancy text-along-path, Codrops on-scroll typography rewritten in Motion (no GSAP), Cult-style 3D carousel, Smooth UI siri-orb / ascii-render, and matter-js gravity. Group B items (lamp-heading, tracing-beam, container-scroll-3d, circular-gallery, glowing-edge, scroll-image-sequence, pixel-transition) are original implementations credited as “灵感来自 X，原创实现”; Aceternity / React Bits / Skiper / Hover.dev / Pro / Shadertoy sources were not opened.
- Batch 7 Group A ports `@vfx-js/core` (MIT), OGL Unlicense examples (mouse-flowmap / GPGPU particles / polylines), hexagoncircle/pixel-canvas (MIT), Atropos (MIT), rough-notation (MIT), Fancy marquee-along-svg-path (MIT), and a Motion rewrite inspired by mo.js (MIT, source not copied). Group B items (evervault-card, canvas-reveal, letter-glitch-wall, target-cursor, lightning, iridescence, silk) are original implementations credited as “灵感来自 X，原创实现”; Aceternity / React Bits / Skiper / Hover.dev / Pro / Shadertoy sources were not opened. Heavy WebGL packages (`ogl`, `@vfx-js/core`) stay as per-item optional registry dependencies.
- Batch 8 adds a `sections/` category of landing-page blocks (hero- / footer- / nav- / section-*), separate from `marketing-blocks`. Background effects are swappable slots; `prefers-reduced-motion` falls back to a static gradient. Group A ports cobe (MIT, markers + arcs), Fancy curtain footer (MIT), Cult sticky feature scroll (MIT), and Kokonut free MIT morphing nav (Pro not used). Group B items (`hero-ai-prompt`, `hero-parallax-wall`, `footer-giant-wordmark`) are original implementations credited as “灵感来自 X，原创实现”; Aceternity / v0 / Lovable / Preline / shadcnblocks / Tailwind Plus / Pro sources were not opened. `cobe` and `matter-js` stay as per-item optional registry dependencies. GSAP and tldraw were not used.
- Batch 9 adds card/navigation effects and a `templates/` category. Group A rewrites Smooth UI coverflow / book-flip / folder-reveal (MIT), Fancy box carousel (MIT), Kokonut free detent dial and activity rings (MIT, Pro not used), Cult family drawer (MIT), Motion Primitives text morph (MIT), Animata 3D orbit (MIT), and a Magic UI portfolio-shaped page (MIT structure, effect-ui components). Group B items (`apple-cards-carousel`, `saas-template`, `ai-product-template`, `devtool-template`, `agency-template`) are original compositions credited as “灵感来自 X，原创实现”; Aceternity / Awwwards / Magic UI Pro / Once UI magic-portfolio / Launch UI paid / Tailwind Plus / Preline / shadcnblocks sources were not opened. Each template is a multi-file registry item (`page.tsx` + `content.ts` + `theme.ts`). Heavy WebGL is `React.lazy`; `prefers-reduced-motion` skips those chunks and shows a static gradient. Docs expose `/preview/{slug}` full-screen. GSAP and tldraw were not used.
- Kokonut UI is used only as free GitHub MIT references; Pro components were not used.
- Paper Shaders LICENSE/NOTICE are vendored in `licenses/apache/paper-shaders/`. The only modification is a thin React wrapper (`shader-backgrounds`) that selects presets and palettes.
- React Bits was reviewed and **not** copied: its MIT + Commons Clause license forbids redistributing or porting the components themselves.
- Aceternity UI was reviewed and **not** copied due to a non-standard license.
